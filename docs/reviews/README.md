# Review reports

Reports from the verification sub-agents. See [PLAN.md](../../PLAN.md) section 1.

File names:
- `phase-<n>-iter-<m>-verify.md`
- `phase-<n>-iter-<m>-break.md`
- `phase-<n>-iter-<m>-audit.md`
- `final-F1-correctness.md`, `final-F2-security.md`, `final-F3-product.md`
- `known-issues.md` — medium and low findings left unfixed at code freeze

Final reviewers must not read this folder. Each final review is independent.
