# Scripts

Created in Phase 0.

| Script | What it does |
|---|---|
| `run_eval.py` | Runs the test sets in `data/eval/` and prints caught, missed and wrongly flagged |
| `seed_demo.py` | Loads the demo club from `data/demo/` |
| `fetch_sources.py` | Saves snapshots of the official documents to `rules/sources/` with the fetch date |
| `validate_rules.py` | Checks every rule file has the required fields and matches its snapshot |
